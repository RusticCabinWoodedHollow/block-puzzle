# Block Puzzle

PWA-головоломка в дзен-неон стиле: заполняй поле 8×8 фигурами (как в тетрисе, но ставишь **вручную** — тянешь с подноса). Полные линии (горизонталь или вертикаль) исчезают, сверху новые фигуры падают некуда — просто освобождаются клетки.

## Правила

- Внизу — **3 фигуры** на выбор. Перетащи одну на поле — на её место сразу выпадает новая.
- Повернуть фигуру нельзя — ставь как есть.
- **Без счёта и таймеров.**
- **Проигрыш**: когда ни одна из трёх фигур нигде не помещается (невозможные фигуры сереют).

## Особенности

- Кнопка «Установить приложение» в шапке — PWA работает офлайн (service worker).
- Шапка: ☀️/🌙 тема, ↻ новая игра (подтверждение вторым тапом), 📲 установка.
- Неон-стиль (тёмная navy + циан), шрифт Russo One (офлайн).

## Структура

Статический HTML/CSS/JS, без сборки. Деплой — корень репо (GitHub Pages, подпуть `/block-puzzle/`).
